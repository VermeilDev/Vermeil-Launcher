# Contributing to Vermeil

Vermeil is an open-source project guided by its creator and project lead. The source code is publicly accessible for auditability, privacy verification, and personal use.

---

## 🚫 Closed Contribution Policy

To maintain architectural cohesion and keep maintenance sustainable, Vermeil does not accept external code contributions:

- **No Pull Requests**: Unsolicited PRs, automated dependencies bumps, or refactors will be closed without review.
- **No External Commits**: All codebase changes are directed and maintained by the creator and project lead.

If you wish to make custom changes, add new features, or experiment with the code, you are encouraged to **fork the repository** under the terms of the [GNU General Public License v3.0](LICENSE).

---

## 💬 How to Participate

Community participation is welcomed in non-code formats:

- **Bug Reports**: Open an issue on GitHub detailing the observed behavior, reproduction steps, launcher version, operating system, and relevant crash logs.
- **Feature Suggestions**: Open an issue describing what you would like to see and how it aligns with Vermeil's tactile, privacy-focused design philosophy.

All participants in GitHub Issues and discussions are expected to adhere to our [Community Code of Conduct](CODE_OF_CONDUCT.md).

---

## 🛠️ Building from Source

If you want to build and run Vermeil locally for your own personal use, refer to the [Developer Guide](docs/DEVELOPMENT.md).
