# Support & Community Resources

Thank you for using Vermeil!

## Getting Help

### 1. Documentation & Architecture
Before opening an issue, please check our documentation:
- **[README.md](README.md)**: Installation, highlights, and quick-start guide.
- **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**: Developer setup, build instructions, and architecture specifications.
- **[PRIVACY.md](PRIVACY.md)**: Data privacy architecture, zero-telemetry guarantees, and local credential storage.

### 2. Issue Tracker
If you encounter a bug or have an enhancement request:
- **Bug Reports**: Search [existing issues](https://github.com/VermeilDev/Vermeil-Launcher/issues) to avoid duplicates. If new, open a report using our structured template.
- **Feature Requests**: Submit proposals using our feature request template.

### 3. Security Vulnerabilities
If you discover a security issue or vulnerability, **please do not open a public issue**. Report it privately via:
- **[Private Vulnerability Reporting](https://github.com/VermeilDev/Vermeil-Launcher/security/advisories/new)**

## Supported Platforms
- **Operating Systems**: Windows 10/11 (64-bit), Linux (modern distributions with WebKitGTK 4.1).
- **Minecraft Versions**: Java Edition releases supported by Fabric, Quilt, NeoForge, and Forge.
- **Java Environments**: Adoptium Temurin OpenJDK (Java 8 through 25, automatically managed).
