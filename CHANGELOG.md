## 0.1.0 (Alpha Build 10)

### Changed

- Set Compact (`1100 × 720`) as the default window launch size preset across desktop configurations
- Isolated window size presets to local machine storage, preventing multi-device resolution conflicts during Google Cloud sync
- Unified runtime settings application into a single reactive pipeline across cold boot, local edits, and cloud restoration
- Wired background auto-update polling intervals to start and cancel dynamically when the auto-update setting changes
- Synchronized Windows shell shortcut icons and taskbar indicators automatically upon cloud theme restoration
