## 0.1.0 (Alpha Build 11)

### Added

- Smart crash diagnosis engine analyzing stack traces for RAM exhaustion, Java version mismatches, missing dependencies, and mod conflicts
- Quick summary export formatted for Discord and GitHub issue reports directly from the crash modal

### Changed

- Streamlined crash reporting to open diagnostic modal immediately on crash with foreground window focus
- Reorganized downloads screen filter bar into logical taxonomy with dedicated filters for Resource Packs and Data Packs

### Fixed

- Restored automatic navigation to instance logs tab when launching games via instance cards, instance page header, and quick world/server join
- Refined crash dialog search bar height and icon proportions to match design system standards
- Restored reactive cloud backup timestamp updates on sync completion in Account screen
